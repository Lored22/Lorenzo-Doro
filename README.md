# Vero Seoul — e-commerce concept

A bilingual, mobile-first prototype for a curated Italian gourmet brand in Korea. It includes six pantry products, three gift boxes, persistent demo cart, free-shipping progress, newsletter interaction and a simulated checkout. No orders, personal data or payments are transmitted.

## Preview locally

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Publish with GitHub Pages

1. Create a repository and upload these files to its root.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.

The project uses plain HTML, CSS and JavaScript, so no build step is required.

## Commercial note

Product, producer and regulatory information is illustrative. Before launch, validate Korean import registration, Korean-language labels, allergens, nutrition data, claims, pricing and fulfillment terms.
